## Anti-Patterns Verdict

**LLM assessment:** All systemic AI-template tells from the first run are resolved (per-section eyebrows, gradient-text titles, ambient ember, hero glassmorphism, second-accent dot). The flagship case (Agent Pay / Money20/20) is now a full-width feature, so the headline work is obvious in seconds rather than competing with equal-weight cards. The homepage follows its own DESIGN.md.

**Deterministic scan:** `detect.mjs` → one `warning`: em-dash-overuse in `components/shared/shader-grid.tsx`. **False positive** — all 13 em-dashes are in JSDoc/code comments; the component is a `<canvas>` shader that renders zero text. No user-facing copy affected.

**Visual overlays:** browser automation unavailable; source-based review.

## Overall Impression
The page now reads as senior and composed: one decisive ember accent, clean neutral sections, a clear flagship, and no slop tells. The remaining opportunities are all P3 and outside the homepage's core job.

## What's Working
- **Decisive ember.** One accent for intent (CTA, status, one shimmer word, one warm pool).
- **Clear flagship.** The Money20/20 case leads full-width; supporting work sits in a calm grid.
- **Senior restraint with personality.** Shader grid, portrait tilt, custom cursor — deliberate, not slop.
